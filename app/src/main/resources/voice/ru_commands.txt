# BYDMate built-in voice commands, Russian.
#
# A phrase runs offline only when it equals one phrase of this file, word for word. Anything
# else goes to the cloud agent (or gets «не понял» without it). "A и B" and "A а также B" run
# when every part is a command of this file on its own.
#
# Both the phrase and the template words are normalized the same way: lower case, ё -> е,
# punctuation out, "%" -> "процентов", number words -> digits ("двадцать пять" -> 25).
# Filler words (пожалуйста, можешь, мне, слушай, эй, спасибо, хочу, я) are dropped from the phrase
# and may not appear here.
#
# Lines ("#" starts a comment; a line starting with a space continues the previous one):
#   rule NAME: a|b|...                       alternatives, used as <NAME>
#   list NAME: forms => VALUE ; forms => VALUE
#                                            slot used as {NAME}; forms are |-separated phrases in
#                                            template syntax or number ranges like 10..49
#   range NAME: 16..30                       slot whose value is the number said
#   TEMPLATE => COMMAND                      a phrase and what it runs
#   solo TEMPLATE => COMMAND                 the same, but only as the whole phrase, never as one
#                                            part of "A и B" (a phrase without its own verb would
#                                            take the other part's verb there)
# Template syntax: words, <rule>, {slot}, [optional part], (a|b) choice, a|b at the top level.
# COMMAND: dispatch strings joined by " + ", each {slot} replaced by its value; a value of several
# symbols "a,b" repeats the command once per symbol, in that order. Built-ins:
#   TEMP +1, TEMP -1    cabin temperature one step up or down
#   VOL PAYLOAD         media volume: +1, -1, mute, unmute or a level
# Every template phrase has a row in app/src/test/resources/voice/ru_commands_golden.tsv.

# ---- Verbs ---------------------------------------------------------------------------------

rule open: открой|открыть|откройте|открывай|опусти|опустить
rule close: закрой|закрыть|закройте|закрывай|подними|поднять
# Lids (sunroof, shade, trunk) only open and close: "опусти"/"подними" say nothing clear there.
rule open_lid: открой|открыть|откройте|открывай
rule close_lid: закрой|закрыть|закройте|закрывай
rule ajar: приоткрой|приоткрыть|приспусти|приспустить
rule air: проветри|проветрить
rule set: поставь|установи|сделай
rule on: включи|включить|включите
rule off: выключи|выключить|выключите|отключи|отключить

# ---- How far an opening goes ---------------------------------------------------------------
# A spoken share maps to the widest detent that does not exceed it: windows 10 (vent), 50, 100;
# the sunroof 7 (tilt), 50, 100. Below the smallest detent nothing matches.

rule full: полностью|до конца|на максимум
rule half: наполовину|на половину|на половинку|до половины|на пол
rule little: чуть|чуть чуть|немного|немножко|слегка|на чуть|на немножко|на щелочку|на щелку|на проветривание
rule prep: на|до
rule pct_word: процентов|процента|процент
list frac: на треть|на четверть => 通风 ; на три четверти => 半开
list pct1: 10..49 => 通风 ; 50..99 => 半开 ; 100 => 打开100
list pcts: 10..49 => 通风 ; 50..99 => 半开 ; 100 => 全开
list set1: 0 => 打开0 ; 10..49 => 通风 ; 50..99 => 半开 ; 100 => 打开100
list sets: 0 => 关闭 ; 10..49 => 通风 ; 50..99 => 半开 ; 100 => 全开
list roof_pct: 7..49 => 天窗通风 ; 50..99 => 天窗打开50 ; 100 => 天窗打开100
list roof_frac: на треть|на четверть => 天窗通风 ; на три четверти => 天窗打开50

# ---- Windows -------------------------------------------------------------------------------
# A bare singular "окно" and "моё окно" are the driver's; "левое"/"правое" alone are the rear
# ones (the front ones are the driver's and the passenger's).

rule okno: окно|окошко|стекло
list win: <okno>|мое <okno>|<okno> водителя|<okno> у водителя|<okno> на водительской стороне
        |водительское [<okno>]|переднее левое <okno>|<okno> спереди слева|<okno> слева спереди
        |форточку|форточку водителя|водительскую форточку => 主驾 ;
    <okno> пассажира|<okno> у пассажира|<okno> на пассажирской стороне|пассажирское [<okno>]
        |переднее правое <okno>|<okno> спереди справа|<okno> справа спереди
        |форточку пассажира|пассажирскую форточку => 副驾 ;
    левое <okno>|заднее левое <okno>|<okno> сзади слева|<okno> слева сзади|левую форточку [сзади] => 后左 ;
    правое <okno>|заднее правое <okno>|<okno> сзади справа|<okno> справа сзади|правую форточку [сзади] => 后右
list wins: окна|все окна|стекла|все стекла|окошки|окна в машине|передние и задние окна => 车窗 ;
    передние окна|все передние окна|передние стекла|окна спереди|окна водителя и пассажира
        |стекла водителя и пассажира => 前排车窗 ;
    задние окна|все задние окна|задние стекла|окна сзади|заднее окно => 后排车窗

# Every window but some: each door that is left gets its own command.

    пассажирского [окна]|пассажира|переднего правого [окна] => 主驾,后左,后右 ;
    заднего левого [окна] => 主驾,副驾,后右 ;
    заднего правого [окна] => 主驾,副驾,后左 ;
    задних [окон] => 主驾,副驾 ;
    передних [окон] => 后左,后右 ;
    водительского [окна] и пассажирского [окна]|водителя и пассажира => 后左,后右 ;
    заднего левого [окна] и заднего правого [окна] => 主驾,副驾

# ---- Seats ---------------------------------------------------------------------------------
# A seat without a side is the driver's; the car is left-hand drive, so "левое" is the driver's
# seat and "правое" the passenger's. Levels 1..3; "на полную"/"на максимум" is 3.

rule heat: подогрев|обогрев
rule blow: вентиляцию|вентиляция|обдув
rule seat1: сиденья|сидения|сиденя|кресла
rule seats: сидений|кресел
list seat: <seat1>|<seat1> водителя|водительского <seat1>|моего <seat1>|левого <seat1>
        |переднего левого <seat1> => 主驾 ;
    <seat1> пассажира|пассажирского <seat1>|правого <seat1>|переднего правого <seat1> => 副驾 ;
    <seats>|всех <seats>|обоих <seats>|передних <seats>|<seats> водителя и пассажира
        |<seats> слева и справа => 主驾,副驾
list lvl: [на] 1|[на] первый [уровень]|[на] минимум => 1 ;
    [на] 2|[на] второй [уровень] => 2 ;
    [на] 3|[на] третий [уровень]|[на] максимум|на полную => 3

[<on>|<set>] <heat> {seat} => {seat}座椅加热1档

<off> <heat> {seat} => {seat}座椅加热关闭
[<on>|<set>] <blow> {seat} => {seat}座椅通风1档
[<on>|<set>] <blow> {seat} {lvl} => {seat}座椅通风{lvl}档
{lvl_ord} уровень (вентиляции|обдува) {seat} => {seat}座椅通风{lvl_ord}档
