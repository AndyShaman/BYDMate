# Яндекс Алиса в BYDMate

## Интеграция

В разделе «Голосовой помощник» пользователь выбирает:

- BYDMate / TTS
- Яндекс Алиса

Для Алисы используются Endpoint URL и API Key. Кнопка на руле и выбор навигатора общие для обоих помощников.

Поддерживается **полноценный голосовой помощник Яндекс Алиса** и управление автомобилем через semantic-команды.

Основные группы команд:

- климат, температура, вентилятор и направления обдува;
- подогрев и вентиляция сидений;
- свет салона;
- окна, включая позицию 0-100%;
- задний багажник, люк и шторка;
- запуск приложений;
- управление медиа;
- навигация на приборной панели.

`app.navigation.open` открывает выбранный в BYDMate навигатор:

- Яндекс Навигатор
- Яндекс Карты
- 2ГИС
- Waze
- Google Maps

## DiLink 3 support

На Android 10 / DiLink 3 одно нажатие кнопки микрофона создаёт keycode 304 и 327. При включённой Алисе 304 запускает Алису, а 327 блокируется, чтобы не запускался второй помощник.

BYDMate также позволяет полностью отключить штатный BYD Assistant через существующую настройку. Отключение обратимо; вместе со штатным помощником отключается приложение Shortcuts.

Алиса запускается через Яндекс Браузер с Accessibility-поиском кнопки, retry и поддержкой warm/cold start.

Для окон и люка процентная команда проверяется по телеметрии. Если DiLink 3 подтверждает команду без фактического движения, используется движение + контроль позиции + STOP.

Расширенные режимы обдува 6/7 остаются через отдельный `ac_wind_mode_ext`.

## Безопасность

- задний багажник открывается только при известной скорости 0 км/ч;
- люк не открывается при неизвестной скорости или выше 80 км/ч;
- окна не открываются при неизвестной скорости или выше 120 км/ч;
- закрытие окон и люка этими ограничениями не блокируется;
- raw/FID-команды через Alice bridge не принимаются.

## Bug fixes / support

- GigaAM: прерванная загрузка продолжается через HTTP Range;
- навигация: добавлены Waze и Google Maps;
- Alice polling использует собственный актуальный snapshot автомобиля;
- настройки Алисы локализованы;
- reference Worker подготовлен для Cloudflare и запуска на обычном VPS.

## Reference Worker

`reference/alice-worker/` содержит single-car reference implementation.

Для VPS используется:

- `worker.mjs` - логика Yandex Smart Home + BYDMate API;
- `server.mjs` - Node.js адаптер;
- `d1-sqlite.mjs` - D1-compatible слой поверх SQLite;
- примеры systemd, nginx и переменных окружения.

Worker сохраняет расширенный каталог semantic actions как референс. Неподдерживаемые Android-команды BYDMate безопасно отклоняет.
